# Hotel Network Design

This repository contains my intermediate-level hotel network project, designed and built in Cisco Packet Tracer. I created the network to simulate a realistic hotel environment, including guest Wi-Fi, employee networks, hotel operations, POS systems, servers, IoT devices, management networks, and other essential hotel services. 

## Learning Goals

Through this project, I aim to develop practical experience in: 

* Designing a structured network using core, distribution, and access layers.
* Creating VLANs and using network segmentation to separate guests, employees, POS systems, servers, IoT devices, and management traffic.
* Configuring inter-VLAN routing and understanding how traffic moves between different network segments.
* Implementing OSPF for dynamic IPv4 routing and OSPFv3 for IPv6 routing.
* Building a dual-stack IPv4/IPv6 network and troubleshooting connectivity across both protocols.
* Implementing redundancy with HSRP, Rapid PVST+, and EtherChannel.
* Understanding STP root bridge selection and how Layer 2 redundancy affects traffic paths.
* Applying network security controls such as ACLs, port security, DHCP snooping, Dynamic ARP Inspection, and BPDU Guard.
* Configuring common network services such as DHCP, DNS, NAT, NTP, and Syslog.
* Practicing secure device management using SSH and management VLANs.
* Testing network behavior and verifying configurations using Cisco IOS troubleshooting commands.
* Troubleshooting real-world problems such as VLAN mismatches, routing failures, failed links, STP issues, ACL restrictions, and DHCP problems. 

The overall goal is to move beyond configuring individual networking concepts and develop the ability to design, implement, verify, and troubleshoot a complete network as an integrated system.
